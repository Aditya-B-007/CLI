kautilya

A terminal-native, user-specific log intelligence tool that learns normal system behavior and flags anomalies in real time using deterministic rules.
Developers constantly deal with logs, but: 
1. logs are noisy and repetitive
2. identifying what matters takes time
3. existing tools are either too generic or too complex
This tool addresses a very specific gap:
-> It tells you what is unusual in your system, not just what exists.

Instead of analyzing logs in isolation, the tool:
1. Learns baseline behavior from historical logs
2. Monitors new activity after every terminal command
3. Highlights deviations, rare events, and patterns

All of this happens:
1. locally
2. without AI
3. with near-zero latency
